# TTS output

**Status:** Done

Implements the settled behavior in `specs/tts-output.md` ("`say`") — the `VoiceOutput` class whose `say(text)` coroutine is WICA's output Command (the agent's voice), delegating to the sibling `TTSTools(engine).say` for its guarded, non-raising contract. Delivers only `VoiceOutput` and its unit tests against a fake `TTSEngine`; building the real `TTSEngine` from config and registering `say` as WICA's `output_command` belongs to the app plan (mirrors how [asr-bridge](202609041500_asr-bridge.md) scoped itself).

## Decisions locked in for this plan

1. **No TTS-only e2e test.** The spec's Testing section is reworded to drop the claim of a live ElevenLabs `tests-e2e/` test; a live test covering the *whole* speech interaction (ASR → agent → TTS) may be added later, but a TTS-in-isolation live test is not worth its own credential/audio dependency. This plan ships unit tests only.
2. **`say` delegates, never re-implements.** `VoiceOutput.say` calls `TTSTools(engine).say(text)` and returns its result verbatim — it does not touch `engine.say` directly, so the empty-text guard, the `TTSError` → `"TTS error: <message>"` mapping, and the `"OK"` success string all come from the sibling contract (verified in `tts-engine/src/tts_engine/tools.py`). `TTSTools` is built once in `__init__`.

## Design facts confirmed against the TTS engine

(Verified in `tts-engine/src/tts_engine/tools.py` and `engine.py`; imported here from the sibling package already on the path.)

- `TTSTools(engine).say(text)` is async and non-raising for expected conditions: empty `text` returns `"TTS error: text must not be empty"` **without** calling the engine; a `TTSError` from `engine.say` is logged and returned as `"TTS error: <message>"`; success returns `"OK"`.
- `TTSEngine.say(text)` awaits until streaming playback drains (`finally: self._sink.drain()`), so a `say` Command stays `running` in the World for the real duration of the utterance.
- `TTSEngine` needs no `start`/`stop` — it is ready once constructed — so `VoiceOutput` only needs the engine to call `say`; no lifecycle methods to wire.
- `TTSError` lives in `tts_engine.modules.base` (what the tests raise from the fake engine).

## Steps

1. **Module + imports** in `tts_output.py`: `from __future__ import annotations`; import `TTSEngine` from `tts_engine.engine` and `TTSTools` from `tts_engine.tools`.

2. **`VoiceOutput.__init__(self, engine: TTSEngine)`**: store `self._tools = TTSTools(engine)`. Building the tools wrapper once keeps `say` a thin delegate.

3. **`async say(self, text: str) -> str`** with the spec's agent-facing docstring verbatim (the "This is your voice…" text — it is what the model sees as the voice's description). Body:
   ```python
   return await self._tools.say(text)
   ```
   No guard or error handling here — the guarded, non-raising contract is `TTSTools.say`'s job. `VoiceOutput.say` is a bound method, so registering it as `output_command` preserves its name, signature, and docstring.

4. **Rework `specs/tts-output.md` Testing section** (decision 1): keep the three unit expectations, but replace the closing parenthetical that asserts a live ElevenLabs `tests-e2e/` test with a note that there is no TTS-only live test and a whole-interaction (ASR→agent→TTS) e2e may be added later. Set the frontmatter `tests:` list to `tests/test_tts_output.py`.

## Tests (`tests/test_tts_output.py`)

Functional, no audio, no network. A `FakeTTSEngine` records the `text` of each `say` call and can be configured to raise a `TTSError`; exposes just `async say(self, text)` — the only method `TTSTools` calls. Pass it with `cast("TTSEngine", fake)` so the `engine: TTSEngine` annotation type-checks. Drive the public `VoiceOutput.say` the way WICA will (a real caller), not the internal `TTSTools`.

- **Happy path**: `await say("hello")` returns `"OK"` and the fake recorded exactly one call with `"hello"`.
- **Empty text is guarded**: `await say("")` returns `"TTS error: text must not be empty"` and the fake recorded **no** call — the guard short-circuits before the engine.
- **Synthesis error is mapped, not raised**: a fake whose `say` raises `TTSError("boom")` makes `await say("hi")` return `"TTS error: boom"` (no exception propagates).

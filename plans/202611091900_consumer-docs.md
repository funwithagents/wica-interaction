# Consumer documentation: README as landing page, docs/ by task, CONTRIBUTING, docs checks

**Status:** Done

Implements [specs/project.md](../specs/project.md) ("Repo shape", "Documentation checks"): the reader-facing documentation the sibling repos converged on (`wica-framework`, `reachy-mini-bridge`, `tts-engine`), adapted to an application rather than a library. One sentence: give someone who wants to *run* the app, on their machine or their robot, a place to start that is not a spec, and keep it honest with a test. It deliberately leaves out a developer guide for adding an embodiment (the [embodiment spec](../specs/embodiment.md) serves that reader) and any CI wiring ([specs/testing.md](../specs/testing.md), open question 1).

## The shape

The siblings' pattern, kept as is:

- **README.md** is the landing page, in the siblings' section order: what it is and a "Start here" list, a Project status box, a feature table, Install, Quick start, Documentation, How it is developed, License.
- **docs/** is the consumer documentation, entered through `docs/index.md` ("I want to… / Read"): `getting-started.md`, `reference/` (what a reader looks up), `guides/` (one page per task, troubleshooting among them).
- **CONTRIBUTING.md** says how the project is run: one maintainer, feedback through issues, no external pull requests yet.
- **One home per fact.** A reference page owns a fact; every other page links there. The specs stay the normative design (the *why*, every guarantee, the open questions); AGENTS.md stays the operating manual.
- **A docs test** (`tests/test_docs.py`, the fast tier) keeps the Markdown honest: links and anchors resolve, the tables that mirror code match it.

What differs from a library: there is no API reference. The references here are the **config file** (every section of the one JSON), the **install** (extras, platforms, first-run downloads) and the **agent's surface** (what the model sees and can do — what a persona author needs).

Sibling documentation is **linked by GitHub URL** in README and `docs/` (a reader there has no checkout next door); the specs keep referencing it by repo-qualified path, as decided on 2026-11-03.

**Status:** Todo

## Steps

1. **Dependencies.** Add `app-setup[ui]` and its source; point the four siblings at `setup-contract`; `uv lock`, `uv sync --dev`. Check the lock resolves `tts-engine` once (the bridge's URL and ours identical). Run the current test suite: note what the siblings' breaking changes break before any change here (`MissingEnvError`'s alias, the loaders' `base_dir`, a config with a key refused) so each is fixed where it belongs below.
2. **`fields.py`.** Copy the helper and its tests; `tests/test_fields.py` passes unchanged but for imports.
3. **The declarations and the loaders.** In `setup.py`, declare each app-owned section's fields once (name, kind, description, default, bounds, `advanced` for vision's tuning fields; `audio_processing`'s two features as two optional objects, each with its own fields). Rewrite `VisionConfig.from_dict`, `CameraConfig.from_dict` and the audio-processing parser over `read_fields`, keeping every rule of the specs (the bool-is-not-an-int guards, `max_hands` an integer, `level` 0–3, an unknown key refused at each level, `null` features meaning defaults). Messages become the helper's, prefixed `config: <section>.<field>`; update the tests' expected messages, not the rules they pin.
4. **The contracts.** `VISION`, `AUDIO_PROCESSING`, `CAMERA`: `config_schema` from the declarations (titles "Hand signs", "Microphone processing", "Camera"; distribution `wica-interaction`); `check_config` from `field_problems` plus the unknown-key and not-an-object problems, each at its JSON Pointer; `required_extras` from the switches, tolerant of anything; `check_setup` with the extra's imports tried in one function per section (seams the tests replace), then for vision the two model items (`required: False`, `preparable: True`), every key of an item present; `prepare(config, item, *, on_progress, base_dir)` for the two models (the landmarker through `ensure_model`, the classifier through `huggingface_hub.snapshot_download` with byte progress), `ValueError` for any other item; `options` returning `[]`; `probe` as the spec's table, timed, never raising, releasing what it built. All four machine functions take `base_dir` and ignore it.
5. **The shared and embodiment loaders.** `load_app_config(data, base_dir=…, sections=…)` and both `load_config(data, *, base_dir)`; every owner's `from_dict` gets `base_dir`. Remove `read_config_file` and `engine_block`. Error messages name `config`, the section and the field.
6. **The defaults.** Move the two templates and the two personas into `<embodiment>/default/`; unwrap `asr` and `tts`; drop `api_key_env: "WICA_HF_TOKEN"`; persona by bare name; one field per line. Confirm the built wheel contains the four files (`uv build`, list the archive). **Stop here for the user's review of the two default configs before committing them.**
7. **The apps.** In each `app.py`: `DEFAULT_CONFIG` read from the package's `default/config.json`, `SECTIONS`, `APP`, `ensure_persona(folder)`, and `main()` calling `run_app`.
8. **`run_app`.** Signature `run_app(app, *, load, embodiment, ensure_persona)`. Parse `--folder` (default `default_folder(app.name)`); build `AppModel(app, ConfigFolder(folder, app.default_config))` (the folder made, the default written, the `.env` loaded); `ensure_persona(model.path)`; `load(model.used_config(model.saved_config()), base_dir=model.path)`, a `ValueError` (and `FolderError`, a `ValueError`) still opening the degraded page with its message; then `build_system` and `_serve` as today. Replace `MissingEnvError` / `.env_var` by `MissingSecretError` and its message. No blockers check, no lock, no autostart, no `--host` / `--port` yet: this plan changes where the config comes from, nothing else.
9. **Audio-processing messages.** `asr.engine.audio_source` → `asr.audio_source` in the two error strings and their tests.
10. **Tests.** `tests/test_setup.py` as the spec's "Testing" lists, the carrier test included (exceptions: `reachy-mini-bridge[placo]`, `asr-engine[kyutai-mlx]`, `asr-engine[kyutai-torch]`); `tests/<embodiment>/test_app.py`; the config tests rewritten over documents and `base_dir` (a persona found against a temporary folder while the working directory is elsewhere); `tests/test_system.py`'s `run_app` tests over a temporary `--folder`. `tests/test_docs.py`: the heading-per-section check reads each app's `SECTIONS`.
11. **The end-to-end tier.** Unwrap both configs, name the personas by bare name, keep `api_key_env` explicit (`WICA_ANTHROPIC_API_KEY`, `DEEPGRAM_API_KEY`); the fixtures load the JSON themselves, fill in what the run controls (`asr.audio_source.device`, `tts.player.device`, …) and call `load_config(document, base_dir=<the embodiment's default folder>)`. Run the tier locally with the keys at hand (`uv run pytest tests-e2e -rs`).
12. **Docs, README, AGENTS.md.** Every `--config <file>` instruction becomes "run the command; its folder is …; edit `config.json` there" (the Setup tab arrives with the next plan, and the docs say so nowhere yet); the configuration reference documents `asr` and `tts` without `engine`, the keys by default variable, and the folder's files; the personas guide points at the folder's copy. The project map gains `setup.py`, `fields.py`, the `default/` folders, loses `prompts/` and the templates.
13. **By hand.** Launch each app on a new folder (`--folder` under the scratch directory): the default config and the persona appear, the session runs as before; relaunch after editing the persona and a field of `config.json`: both are kept and used. On the robot's app, once against the simulator.
14. **Statuses.** [specs/setup.md](../specs/setup.md), [specs/configuration.md](../specs/configuration.md), [specs/audio-processing.md](../specs/audio-processing.md), [specs/e2e.md](../specs/e2e.md) → `Implemented`. [specs/computer-embodiment.md](../specs/computer-embodiment.md) and [specs/reachy-embodiment.md](../specs/reachy-embodiment.md) → `Implemented` (their entry point's `run_app` call is in place; what `run_app` does next is app.md's). [specs/app.md](../specs/app.md) and [specs/project.md](../specs/project.md) stay `Updated` (the flags, the page). [specs/session.md](../specs/session.md) stays `Stable`. This plan → `Done`.

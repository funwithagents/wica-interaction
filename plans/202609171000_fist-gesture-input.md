# Fist gesture input

**Status:** Done

Implements [specs/gesture-input.md](../specs/gesture-input.md) in full, plus the `vision` config section it needs ([specs/configuration.md](../specs/configuration.md), "The `vision` section") and the app-side composition, UI line, and persona rule ([specs/app.md](../specs/app.md)). Delivers: `vision-modules` as an editable sibling dependency; a `GestureInput` module that polls the robot camera through the bridge, runs the hand + gesture pipeline at 5 fps with a 0.55 threshold, delivers `"fist"` / `None` changes to a callback, and measures each stage's achieved fps the hand demo's way; the `hand_gesture` World entry that triggers the agent only on `None → fist`; the `vision` config section with its `enabled` switch (off by default); a Vision status line in the UI (hand label and score, stop-sign state, achieved fps next to the target, errors); and the persona's "Stop sign" rule. Leaves out: any gesture other than `fist`, debouncing, a camera view in the UI (spec open questions).

## Steps

1. **Dependency.** Add `"vision-modules[hand]"` to `dependencies` and `vision-modules = { path = "../vision-modules", editable = true }` to `[tool.uv.sources]`; `uv sync --dev`; document it in `specs/project.md`, `README.md` ("Sibling dependencies"), and the AGENTS.md map.
2. **Config.** In `config.py`: `VisionConfig(enabled: bool = False, threshold: float = 0.55, fps: float = 5.0, device: str | None = None)` with `from_dict` validation (object; unknown keys rejected; `enabled` a boolean; `0 ≤ threshold ≤ 1`; `fps > 0`; `device` a string or `null`), `AppConfig.vision: VisionConfig | None`, and `load_config` parsing the optional `vision` section (absent ⇒ `None`; vision runs only when `enabled` is `true`, so a tuned section can stay in the file with vision off). Tests in `tests/test_config.py`: defaults, round-trip, invalid values naming the field, the present-but-disabled case.
3. **`gesture_input.py`.** `RobotCameraSource` (paced poll of `api.get_camera_frame()` on the loop; `None` frame ⇒ wait and retry; raise ⇒ `capture_error`, keep polling; `close()` ⇒ `read()` returns `None`). `GestureInput`: build `StreamProvider(source)` → `HandStage` → `GestureClassifier` (threshold, fps, device, injected models), a watcher thread that reduces each new result to `"fist"` / `None` and calls `on_gesture` on change only, and samples each node's `published_count` (the stream provider's and both stages') once per `fps_window_s` (default 1 s) into a `_FpsMeter` (Δcount / Δtime — the hand demo's meter); `start` / `stop` (idempotent, joining); `running`; `status()` with `gesture`, `label`, `confidence`, `target_fps`, `stream_fps`, `hand_fps`, `classifier_fps`, `capture_error`, `error`. `RobotCameraSource.fps()` (the protocol's nominal rate) returns the poll rate. `FIST` and `fist_raised(old, new)`.
4. **Tests for 3** in `tests/test_gesture_input.py`, per the spec's Testing list (scripted `HandDetector` returning one box, scripted `ImageClassifier` with a settable score map, fake api returning synthetic frames or raising; a short `fps_window_s` to see both achieved rates appear).
5. **App wiring.** `_hand_gesture` serialize_fn; register `hand_gesture` (`triggers_llm_call=True`, `trigger_condition_fn=fist_raised`, `bypass_coalescing=True`) and build `GestureInput(api, loop, on_gesture=_deliver_gesture, …)` when `config.vision.enabled` and the robot is up (after WICA; `gesture_models=` seam; a construction failure ⇒ `Vision: …` in `missing`; `enabled: false` builds nothing and registers no entry). `AppSystem.gesture`. `_start` starts it after the agent; `_shutdown` stops it after `wica.close()` and before the bridge/api steps, isolated. Tests in `tests/test_app.py`.
6. **UI.** `display_entry`: `hand_gesture` → `✊ fist raised` / `🖐️ fist lowered`. `tick_vision(system) -> str` (`_Vision off._` without a `GestureInput`; else running/stopped, the label + confidence or "no hand", the stop-sign state, `stream: s fps (poll t) · hand stage: x fps (target t) · classifier: y fps (target t)` with an em dash before the first sampling window, `⚠️ camera: …` / `⚠️ error: …`), added to the ASR timer's outputs under a "Vision" heading; when `system.gesture` exists, a snapshot folder box and **Save detector snapshot** / **Save classifier snapshot** buttons whose click handlers call the gesture input's save methods and show the returned status (the hand demo's controls). Tests in `tests/test_app_ui.py` (the line) and `tests/test_gesture_input.py` (the save methods).
7. **Persona.** Add the "Stop sign" section to `prompts/assistant.md` as the spec words it: cancel everything running, start nothing new, confirm out loud in the next turn (brief acknowledgement if nothing was running), never in the same turn as the cancel, and no reaction to the fist being lowered.
8. **Docs.** `config.example.json` gains `"vision": {"enabled": false, "threshold": 0.55, "fps": 5, "device": null}`. Update `specs/app.md` (data flow, World entries, Vision line, build/start/teardown, degrade axis, out-of-scope), `specs/configuration.md` (the `vision` section), `specs/_overview.md` (vision is in), `specs/_index.md` (row), `AGENTS.md` (map), `README.md`.
9. **Live tier.** `tests-e2e/test_gesture_input_live.py`: a fake api serving `../vision-modules/tests-e2e/fixtures/hand_fist.jpg` must deliver `"fist"` within a generous timeout; `no_hand.jpg` must deliver nothing; skip when the fixtures are absent or the models cannot be loaded.
10. **Statuses.** `gesture-input.md` → `Implemented`; `configuration.md` and `app.md` back from `Updated` → `Implemented`; this plan → `Done` (file + both indexes).

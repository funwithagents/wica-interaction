# ASR bridge

**Status:** Done

Implements the settled behavior in `specs/asr-bridge.md` — the `AsrBridge` that owns the live `ASREngine`, maps its segment stream onto the World (final segments → `on_final_segment`, interims → a live display view) and exposes the agent's `start_dictation` / `stop_dictation` commands. Delivers only the bridge and its unit tests against a fake engine; building the real `ASREngine` from config and wiring the bridge into WICA + the Gradio ASR panel belongs to the app plan.

## Decisions locked in for this plan

Two spec ambiguities were resolved before writing this plan (both fold into the spec here):

1. **Dictation commands never raise.** `start_dictation` / `stop_dictation` are agent-facing WICA Commands (and `stop_dictation` also backs the UI stop button), so they catch the engine's `ValueError`s (not running, already dictating, no dictation in progress, unknown mode) and return a readable status string instead — the same non-raising contract `tts-output.md` gives `say`.
2. **Every final segment fires `on_final_segment`, including an empty/whitespace transcript.** A timeout-mode segment that closes on silence still wakes the agent (with `""`), so the agent can react to the user saying nothing after dictation starts. No empty-final filtering — the spec's segment→world table is implemented literally.

## Design facts confirmed against the ASR engine

(Verified in `asr-engine/src/asr_engine/engine.py` and `segmenter.py`; imported here from the sibling package already on the path.)

- `ASREngine.start()` / `stop()` are async, no args. `start()` always begins in `utterance` mode; the engine never acts on `auto_start` / `auto_start_dictation` itself — so the bridge's `start()` is a plain `await engine.start()`, matching the spec's "app never auto-starts dictation".
- `engine.on_speech_segment` is a public, settable attribute of type `Callable[[SpeechSegment], Awaitable[None]]`. The constructor assigns `engine.on_speech_segment = self._on_segment`.
- `SpeechSegment` (from `asr_engine.segmenter`) has `.transcript`, `.is_final`, `.end_reason`, `.utterances`. For an **interim** segment the engine already builds `transcript` as *committed finals + the in-progress interim*, so `display_text` is just `segment.transcript` — the bridge accumulates nothing itself.
- `engine.start_dictation(end_on_final_segment: bool = True, segmentation_mode: str | None = None)` is async and raises `ValueError` when the engine is not running, when already dictating, or on an unknown mode. `engine.stop_dictation()` is async and raises `ValueError` when not dictating.
- `engine.segmentation_mode` (property) reports the current mode and reads the dictation mode immediately after a successful `start_dictation` — the bridge reads it to build the status string rather than guessing the resolved default. `engine.dictating` (property) is the bool.
- `engine.status()` returns `{"running": bool, "connected": bool}`; the bridge composes its own `status()` from `status()["running"]`, `engine.dictating`, `engine.segmentation_mode`.

## Steps

1. **Module + type alias** in `asr_bridge.py`:
   ```python
   OnFinalSegment = Callable[[str], None]
   ```
   Import `ASREngine` from `asr_engine.engine` and `SpeechSegment` from `asr_engine.segmenter`.

2. **`AsrBridge.__init__(self, engine, *, on_final_segment)`**: store both, initialize `self._display_text = ""`, and wire `engine.on_speech_segment = self._on_segment`.

3. **`async start()` / `async stop()`**: `await self._engine.start()` / `await self._engine.stop()`. No mode argument, no dictation auto-start (the engine begins in `utterance`, which is the app's conversation mode).

4. **`async _on_segment(self, segment)`** — the core segment→world rule:
   - `if not segment.is_final:` set `self._display_text = segment.transcript` and return (World untouched — the agent is not triggered).
   - `else:` call `self._on_final_segment(segment.transcript)`, **then** set `self._display_text = ""`. Fire for every final, empty transcript included (decision 2). Body is all synchronous work, so it never blocks the ASR loop.

5. **`display_text` property** → `self._display_text`. **`status()`** → `{"running": self._engine.status()["running"], "dictating": self._engine.dictating, "segmentation_mode": self._engine.segmentation_mode}` (exactly the three keys the ASR panel reads).

6. **`async start_dictation(self, segmentation_mode: str | None = None) -> str`** with the agent-facing docstring from the spec. Body:
   ```python
   try:
       await self._engine.start_dictation(
           end_on_final_segment=True, segmentation_mode=segmentation_mode
       )
   except ValueError as exc:
       return f"Could not start dictation: {exc}"
   return f"Dictation started ({self._engine.segmentation_mode} mode)."
   ```
   The hard-wired `end_on_final_segment=True` is the "reset on segment end" behavior; the mode string is read back from the engine so it reflects the resolved default.

7. **`async stop_dictation(self) -> str`**:
   ```python
   try:
       await self._engine.stop_dictation()
   except ValueError as exc:
       return f"Could not stop dictation: {exc}"
   return "Dictation stopped."
   ```

## Tests (`tests/test_asr_bridge.py`)

Functional, no audio, no network. A `FakeASREngine` records calls and exposes just what the bridge reads (`on_speech_segment` settable attribute, async `start`/`stop`/`start_dictation`/`stop_dictation`, `status()`, `dictating` and `segmentation_mode` properties); tests push real `SpeechSegment`s (from `asr_engine.segmenter`) through `bridge._on_segment`, as the spec's Testing section prescribes. Pass the fake with `cast("ASREngine", fake)` so the `engine: ASREngine` annotation type-checks.

- **Interim is inert + visible**: an interim segment (`is_final=False`) sets `display_text` to its transcript and does **not** call `on_final_segment`.
- **Final triggers + clears**: a final segment (`is_final=True`) calls `on_final_segment` exactly once with its `transcript`, and `display_text` is `""` afterward.
- **interim→interim→final**: yields exactly one `on_final_segment` call carrying the final text, with `display_text` cleared — the "one utterance, once" contract.
- **Empty final still fires** (pins decision 2): a final segment with `transcript=""` calls `on_final_segment` once with `""` and clears `display_text`.
- **`start_dictation` wiring**: calls the engine with `end_on_final_segment=True` and the passed mode, and returns a string naming the engine's resolved `segmentation_mode`; afterward `status()` reflects the fake's `dictating=True` / `segmentation_mode`.
- **`start_dictation` never raises** (pins decision 1): when the fake raises `ValueError` (e.g. "not running"), the call returns a readable string containing the message and does not propagate.
- **`stop_dictation`**: happy path returns `"Dictation stopped."` and calls the engine; error path (fake raises "No dictation in progress.") returns a readable string, no raise.
- **`status()` composition**: reflects `running` from `engine.status()`, plus `dictating` and `segmentation_mode` from the engine's properties.
